# SE_pro_Paper2podcast
Conference paper management system (Software Engineering project, Spring 2026).

## Run locally
1. cp .env.example .env
2. docker compose up --build
3. API docs: http://localhost:8000/docs  |  Test emails: http://localhost:8025
4. Frontend: cd frontend && npm install && npm run dev  (http://localhost:5173)
